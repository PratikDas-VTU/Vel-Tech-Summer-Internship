# Organization & Orientation

## Introduction to Necurity Solutions
During the first days of the internship, I was introduced to the organizational structure and core service offerings of Necurity Solutions Network Security Pvt. Ltd., specializing in:
* Vulnerability Assessment and Penetration Testing (VAPT)
* Security Audits
* Compliance Consulting

## Orientation Goals
* **Information Security Policies**: Understanding data handling, strict confidentiality rules regarding client VAPT reports, and the ethical boundaries of penetration testing.
* **Workflow Familiarization**: Learning how security analysts document their findings, the severity metrics utilized (CVSS), and the lifecycle of a security assessment from reconnaissance to final reporting.
* **Environment Configuration**: Setting up the mandatory tools and isolated virtual networks required for safe, secure vulnerability research without exposing the host network.
