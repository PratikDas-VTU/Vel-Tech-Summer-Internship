# Linux Fundamentals

## Command Line Administration
Mastering the Linux terminal is a prerequisite for any cybersecurity research. This week focused heavily on navigating file systems and managing permissions entirely via the command line.

### Core Commands Practiced
* **Navigation & Management**: `pwd`, `ls`, `cd`, `mkdir`, `rm`, `cp`, `mv`
* **File Analysis**: `cat`, `grep`, `find`
* **Permissions & Security**: `chmod`, `chown`, `sudo`
* **Network Diagnostics**: `ping`, `ifconfig`, `ip addr`, `netstat`

## Learning Outcomes
By practicing these fundamentals, I transitioned from a GUI-dependent workflow to an efficient, command-line-driven methodology, which is critical when operating headless servers or specialized security distributions.
