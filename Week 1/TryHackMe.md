# TryHackMe

## Foundational Security Training
To bridge the gap between theoretical knowledge and practical application, I completed several foundational modules on the TryHackMe platform.

## Modules Completed
* **OhSINT (Open Source Intelligence)**: Techniques for gathering publicly available information on targets.
* **Linux Fundamentals Part 1**: Reinforcing command-line operations.
* **What is Networking?**: Understanding OSI models, TCP/IP, and basic routing.
* **HTTP in Detail & DNS in Detail**: Deep dive into web protocols critical for web application security.
* **Pentesting Fundamentals**: Learning the standard phases of an assessment (Reconnaissance, Scanning, Exploitation, Post-Exploitation).
* **Offensive & Defensive Security Intro**: Differentiating between Red Team (offensive) and Blue Team (defensive) mentalities.
* **Web Application Basics**: Guided entry-level web pentesting.
