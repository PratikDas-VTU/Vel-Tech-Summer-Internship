# Kali Linux

## Offensive Security Lab
Kali Linux is the industry-standard distribution for penetration testing. I deployed and configured it within VirtualBox to serve as the primary host for offensive security exercises.

## Tool Familiarization
During this setup phase, I familiarized myself with the pre-packaged security tools that would be utilized in later research:
* **Nmap**: For network discovery and port scanning.
* **Burp Suite**: For web application traffic interception and analysis.
* **Metasploit Framework**: For understanding exploit delivery mechanisms.
