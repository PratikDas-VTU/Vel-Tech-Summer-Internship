# OverTheWire: Bandit Wargame

## Practical Command Line Application
The OverTheWire Bandit wargame provides practical, gamified challenges for learning Linux command-line tools in a security context.

## Levels Completed
I completed Levels 0 through 6, which focused specifically on:
* **SSH Connectivity**: Establishing secure remote connections (`ssh`, port manipulation).
* **File Enumeration**: Locating hidden files, reading specific bytes, and dealing with files containing spaces or special characters in their names.
* **Data Extraction**: Using commands like `file`, `strings`, and `base64` to identify and extract passwords hidden within binary data.
