# Week 1: Foundation & Environment Setup

## Objectives
- Establish a functional cybersecurity lab environment using virtual machines.
- Develop proficiency in foundational Linux command-line operations.
- Gain an introductory understanding of penetration testing methodologies, networking, and OSINT.

## Tasks Completed
### Virtual Lab Setup
- **Oracle VirtualBox**: Installed and configured to host isolated testing environments.
- **Kali Linux**: Deployed as the primary offensive security operating system.
- **Ubuntu Linux**: Deployed to practice general server administration and user management.

### Linux Administration Practice
Practiced and documented essential commands:
- Directory navigation and file management (`pwd`, `ls`, `cd`, `mkdir`, `rm`, `cp`, `mv`).
- File analysis and permissions (`cat`, `grep`, `find`, `chmod`, `chown`).
- Network diagnostics (`ping`, `ifconfig`, `ip addr`, `netstat`).

### TryHackMe Modules
Completed foundational cybersecurity training modules:
- OhSINT (Open Source Intelligence)
- Linux Fundamentals Part 1
- HTTP in Detail & DNS in Detail
- What is Networking?
- Pentesting Fundamentals
- Offensive & Defensive Security Intro
- Web Application Basics & Guided Pentest: Web

### OverTheWire: Bandit Wargame
Completed Levels 0 through 6, focusing on SSH connectivity, hidden file enumeration, and file type identification.

## Learning Outcomes
- Acquired hands-on experience navigating and managing Linux file systems securely.
- Developed an understanding of core networking protocols (HTTP, DNS) and their role in web application security.
- Learned the phases of penetration testing (Reconnaissance, Scanning, Enumeration, Exploitation, Reporting) and the importance of structured security assessments.
