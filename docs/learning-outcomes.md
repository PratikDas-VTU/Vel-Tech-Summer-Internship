# Learning Outcomes & Skills Acquired

During the development of the Compliance Checking Application and the broader summer internship, I acquired significant technical and professional skills bridging software engineering with cybersecurity.

## Software Engineering & Architecture
* **OOP and Modular Design**: Gained practical experience architecting scalable, object-oriented systems with distinct validation, parsing, and UI layers.
* **Asynchronous Programming**: Learned to manage UI state and implement non-blocking event loops using Python's threading modules to handle heavy processing tasks seamlessly.
* **Packaging and DevOps**: Successfully navigated the complexities of PyInstaller, learning how to bundle complex dependencies (C-binaries, UI themes, data assets) into a standalone Windows executable.

## Cybersecurity & Compliance
* **Vulnerability Frameworks**: Deepened my understanding of the Common Vulnerabilities and Exposures (CVE) system and the Common Vulnerability Scoring System (CVSS), integrating them programmatically into QA checks.
* **Security Reporting**: Learned the strict compliance, formatting, and terminological standards required for enterprise-grade Penetration Testing and Vulnerability Assessment reports.
* **Automation Implementation**: Successfully transitioned theoretical risk identification into deterministic, automated validation workflows.

## Computer Vision & Data Processing
* **Document Parsing**: Mastered the programmatic abstraction of disparate document formats, efficiently extracting structured metadata and unstructured text from PDFs and Word documents.
* **Image Processing**: Acquired foundational skills in computer vision using OpenCV and NumPy, specifically applying pattern matching algorithms to extract and verify embedded organizational logos.

## UI/UX Design
* **Frontend Development**: Gained proficiency in CustomTkinter, learning how to build modern, cohesive design systems and user-centric dashboards that effectively communicate complex data metrics.
