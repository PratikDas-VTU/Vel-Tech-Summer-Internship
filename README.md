# Vel Tech Summer Internship (2026)
**Cybersecurity Researcher Intern | Necurity Solutions Network Security Pvt. Ltd.**

Welcome to my Summer Internship repository. This repository serves as a chronological journal documenting my 4-week internship experience, from foundational cybersecurity research to the development of an automated enterprise compliance tool.

---

## 📅 Internship Journey

The internship is organized into four distinct weeks, documenting the progression of my learning and responsibilities:

### [Week 1: Foundation & Environment Setup](Week%201/README.md)
* **Focus**: Establishing a virtual cybersecurity lab and mastering foundational Linux administration.
* **Key Activities**: Oracle VirtualBox setup, Kali/Ubuntu deployment, OSINT, and TryHackMe modules.

### [Week 2: Vulnerability Research & Security Reporting](Week%202/README.md)
* **Focus**: Understanding enterprise vulnerability management workflows.
* **Key Activities**: Reviewing 22 VAPT reports, researching CVEs via the NVD, and mapping vulnerable software components.

### [Week 3: Automation Design & Prototyping](Week%203/README.md)
* **Focus**: Transitioning from manual QA to automated software design.
* **Key Activities**: Prototyping the [Compliance Checking Application](Week%203/Compliance%20Checking%20Application.md) and integrating a massive cybersecurity knowledge base.

### [Week 4: Final Development, Testing & Delivery](Week%204/README.md)
* **Focus**: Finalizing the enterprise automation tool.
* **Key Activities**: Implementing a real-time dashboard, generating PDF compliance reports, and testing against sample client data.
* **Reflection**: Read my [Final Reflection](Week%204/Final%20Reflection.md) on the internship experience.
