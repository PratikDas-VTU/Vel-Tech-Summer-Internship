# Compliance Checking Application

*This document summarizes the major software engineering project completed during the internship.*

## Overview
The **Compliance Checking Application** is an enterprise-grade automation tool built to standardize the quality assurance (QA) of Vulnerability Assessment and Penetration Testing (VAPT) reports. It solves the engineering problem of manual, error-prone report reviews by programmatically parsing documents and validating their contents.

## Core Features
1. **Document Parsing Engine**: Automatically extracts raw text, metadata, and embedded assets from complex PDF and DOCX file structures.
2. **Branding Consistency Engine**: Utilizes computer vision algorithms to extract embedded images and cross-reference them against a known database of organizational logos to prevent branding mismatches.
3. **Vulnerability Validation System**: Uses semantic matching to ensure that all referenced vulnerabilities (CVEs) contain their necessary severity metrics (CVSS scores) in the surrounding context.
4. **Dynamic Knowledge Base**: Tracks unknown terms during scans and places them in a "learning queue" for administrator approval, allowing the software to adapt to new terminology over time.

## Architecture & Technology Stack
- **Language**: Python 3.x
- **GUI Framework**: CustomTkinter
- **Document Parsing**: PyMuPDF, python-docx
- **Computer Vision**: OpenCV, NumPy
- **Report Generation**: ReportLab
- **Packaging**: PyInstaller

## Summary
By automating these compliance checks, the application drastically reduces QA turnaround time and ensures a uniform standard of quality across all technical cybersecurity reports generated by analysts.
