# Compliance Checking Application (Initial Concept)

## The Problem
Security analysts generate complex Vulnerability Assessment and Penetration Testing (VAPT) reports in various formats (PDF, DOCX). These reports must strictly adhere to organizational branding, utilize correct industry terminology, and accurately document Common Vulnerabilities and Exposures (CVEs) alongside their respective Common Vulnerability Scoring System (CVSS) metrics. Manual review of these documents is time-consuming and prone to human error.

## The Solution
I proposed and began developing the **Compliance Checking Application**—an enterprise-grade desktop software designed to automate the QA and compliance checking of these reports.

## Early Scope
During Week 3, the initial scope was defined:
* Create a unified parser for PDF and DOCX files.
* Build a dynamic, local knowledge base containing cybersecurity terms, acronyms, and standard English dictionaries.
* Develop a basic graphical interface to allow analysts to easily run the tool without using the command line.
