# Excel Documentation

## Data Structuring & Tracking
To make the vulnerability research actionable for the development and infrastructure teams, I structured the raw data into a comprehensive tracking workbook using Microsoft Excel.

## Workbook Structure
I created a four-sheet Excel workbook mapping the following data points for each affected application environment:
* **Component Name**: The specific library or framework (e.g., jQuery).
* **Current Version**: The outdated version currently deployed.
* **Latest Version**: The target patched version recommended by the vendor.
* **CVE Identifier**: The associated security flaws.
* **Severity Classification**: The CVSS impact score.

## Outcome
This structured documentation provided a clear, actionable remediation roadmap for the engineering teams, transitioning abstract vulnerability data into a manageable format.
