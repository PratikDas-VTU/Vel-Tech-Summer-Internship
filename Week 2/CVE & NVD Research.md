# CVE & NVD Research

## Vulnerability Mapping
After establishing the software component inventory, the next step was to map the identified legacy versions to known security flaws.

## Process
* **NVD Querying**: I utilized the National Vulnerability Database (NVD) to search for publicly disclosed vulnerabilities affecting the specific legacy versions of Angular, Bootstrap, and jQuery discovered in the internal environments.
* **CVE Identification**: Extracted the relevant Common Vulnerabilities and Exposures (CVE) identifiers associated with the outdated software.
* **Severity Classification**: Documented the Common Vulnerability Scoring System (CVSS) severity metrics (Low, Medium, High, Critical) for each CVE to prioritize remediation efforts.
